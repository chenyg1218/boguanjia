播管家

多平台直播跟播辅助。外置中控台连接抖音 / 快手 / 小红书 / 视频号 / 淘宝等，自动发言、弹窗、回复一站搞定。

支持平台

功能介绍一览

顶栏账号切换 + 左侧功能列表 + 主区操作 + 底部运行日志。功能点不额外收费，按账号数区分版本。

打开中控台 外置浏览器连接所选平台中控台；支持浏览器检测、有头 / 无头模式、扫码登录；顶栏可见任务状态。
首次扫码请关闭无头模式。
自动发言 定时发送弹幕文案；支持变量 {宝宝/家人/老铁}（随机择一）、随机空格、置顶、一键刷屏；含快手字数风控提示。
自动弹窗 按小黄车商品序号自动讲解弹窗；支持批量区间（如 1-100）、循环次数、单品 / 全局间隔、随机弹窗、组合快捷键切换商品。
自动回复 监听直播间评论；关键词批量规则（如 音响/音箱|回复A|回复B）；支持 {用户名}、隐藏用户名脱敏；多回复随机选取。
AI 助手 自备 API Key 使用（不计入卡密费用）；可在自动回复中开启 AI 回复，关键词规则优先于 AI。
多账号 专业版最多 3 个账号、旗舰版无上限；各账号独立连接与任务配置，支持账号间复制配置。过期后多余账号自动禁用，本地配置保留。
软件更新 默认通过 Gitee Releases 检查并安装更新；亦可切换 GitHub 或代理源。

改配置后若任务正在运行：请先停止再开始。掉线需重新连接中控台。

系统要求

安装与运行前请确认本机环境满足以下条件。

运行环境

  • 操作系统：Windows 10 / 11（x64）
  • 浏览器：本机 Chrome 或 Edge
  • 网络：可访问所选平台的直播中控台
  • 直播平台账号：对应平台的商家 / 达人身份

安装说明

  • 从官方渠道或商家提供的链接下载安装包
  • 若出现 SmartScreen「已保护你的电脑」：点「更多信息 → 仍要运行」（未代码签名提示，非病毒报毒）
  • 首次连接中控台：关闭无头模式，约 5 分钟内完成扫码
  • 开播并关闭浏览器多余提示弹窗后，再启动发言 / 弹窗 / 回复任务
