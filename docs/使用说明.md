# 播管家 — 开发说明

面向开发者的简要说明。普通用户请看 [用户教程.md](用户教程.md)。

| 项 | 内容 |
|----|------|
| 版本 | V1.0 |
| 系统 | Windows 7 SP1+（x64）；需 VC++ 2015–2019/2022 x64 |
| 跟播页 | https://zs.kwaixiaodian.com/page/helper |
| UI | PySide2（Qt 5.15）：左侧导航 + 工作台 / 账号管理；跟播为 WebEngine |
| 账号 | 免费版 1 个 Profile；专业版（卡密有效）多 Profile，工作台多进程 `--profile` |
| 开发/打包 | Python 3.8 x64 |
| 打包 | `build.bat`（强制 Python 3.8）→ `dist/Boguanjia/`（含 `vc_redist.x64.exe`） |

## 流程

卡密激活 → 扫码（如需）→ 提取直播信息 → 勾选讲解/弹幕/关键字 → 开始运行

## 目录

```
src/boguanjia/   源码
  resources/            内置 license.json、selectors.json（打进 exe）
config/                 开发用配置；发行包仅附带 default_settings.json
data/                   运行配置与 Web Profile（开发态）
scripts/build_exe.py    打包（自动下载并附带 VC++ 运行库）
third_party/vc_redist/  VC++ 安装包缓存（gitignore）
docs/用户教程.md        普通用户教程
```
