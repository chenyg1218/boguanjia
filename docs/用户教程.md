# 播管家 用户教程

顶栏账号切换 + 左侧功能列表 + 主区操作 + 底部运行日志。

**支持平台：** 抖音小店、巨量百应、抖音团购、小红书千帆、小红书蒲公英、视频号、快手小店、淘宝。系统要求：Windows 10 / 11、本机 Chrome 或 Edge。

---

## 一、能做什么

| 功能 | 说明 |
|------|------|
| 打开中控台 | 外置浏览器连接所选平台中控台 |
| 自动发言 | 定时发弹幕；支持变量、随机空格、置顶、一键刷屏 |
| 自动弹窗 | 按商品序号自动讲解弹窗；支持循环次数、快捷键 |
| 自动回复 | 关键词包含/全匹配、多回复随机、冷却、AI 兜底 |
| AI 助手 | 自备 API Key（不进卡密费用） |

**收费计划**：基础版 **0 元 · 1 个账号**；专业版月卡 **29 元 · 3 个账号**；旗舰版月卡 **39 元 · 无上限**。同档续充叠天数；专业有效期内充旗舰卡可升级并叠天。功能点不额外收费。超出档位的账号会自动禁用（配置保留）。

## 二、安装与启动

1. 从官方渠道下载安装包（GitHub Releases 或商家提供的链接）
2. 双击安装。若弹出 **「Windows 已保护你的电脑」**（SmartScreen）：
   - 点 **更多信息** → **仍要运行** 即可继续安装
   - 原因是安装包尚未购买代码签名证书，Windows 对「未知发布者」会提示；**不是病毒报毒**
3. 安装完成后打开「播管家」

开发调试：

```bat
cd desktop
pnpm install
pnpm dev
```

---

## 三、收费计划 / 卡密

1. 顶栏点击 **基础版 / 专业版 / 旗舰版** 徽章，或 **应用设置 → 收费计划**
2. 粘贴卡密 → **激活**
   - 没到期再充：剩余天数会自动加上
   - 同档卡密：延长时间；更高档：可升级并延长时间
   - 更低档卡密：需等当前版本到期后再用（卡不会被扣掉）
3. 卡密绑机；换机联系商家

未激活也能用：仅默认账号。点右上角 **+** 加号时，基础版会提示开通专业版或旗舰版。

## 四、连接中控台（必做）

「打开中控台」页含状态卡片与操作说明。

1. **应用设置 → 浏览器设置**：确认检测到 Chrome/Edge（可自定义路径）
2. 打开左侧 **打开中控台**
3. 在平台下拉框选择目标平台（如快手小店、抖音小店等）
4. **首次扫码请关闭无头模式**
5. 点 **连接直播控制台**，在弹出浏览器扫码
6. 状态变为绿色 **已连接** 后，再去做发言 / 弹窗 / 回复

掉线后需重新连接。换账号或换平台请先断开再连。

> 视频号、淘宝请先开播再连接；淘宝会强制关闭无头模式。

## 五、自动发言

对应侧栏「自动发言」。

1. 在消息列表添加文案（一行一条）
2. **变量**：`{宝宝/家人/老铁}`，发送时随机选一项  
   例：`欢迎{宝宝/家人}进入直播间`
3. 可勾选 **置顶此消息**（平台支持时）
4. **发送设置**：随机发送、间隔秒数、**插入随机空格**、解除字数限制
5. **一键刷屏**：按列表连发（注意冷却，防误触）
6. 点右上角 **开始任务**

> 任务运行中若改了列表或间隔：请先 **停止** 再 **开始**，页面会有黄色提示条。

---

## 六、自动弹窗

对应侧栏「自动弹窗」（商品列表 / 快捷键配置）。

### 商品列表

- 填写小黄车 **商品序号**（如 `1`、`2`）
- **批量添加**：可用区间/列表一次写入，如 `1-100`、`1,3,5-8`（已有序号会跳过）
- **循环次数**：单品反复弹窗次数（单品循环）
- **单品间隔**：0 表示用全局弹窗间隔
- **弹窗设置**：随机弹窗、全局间隔（秒）

### 快捷键配置

- 组合键映射到一组商品序号（如 `Ctrl+Alt+F1` → `1 2`）
- 一般在「自动弹窗」页激活时使用即可；无需刻意开全局快捷键
- 快捷键请用组合键，避免与系统快捷键冲突

点 **开始任务** 后按间隔自动弹；也可用快捷键手动切商品。

---

## 七、自动回复

侧栏「自动回复」：左评论列表、右回复预览；可进 **设置**。

1. 在设置中选择该平台可用的 **监听来源**
2. 先 **开始监听**，再 **开始任务**
3. **关键词回复**：配置关键词与多条回复（随机发送）；可选冷却  
   批量格式示例：`多少钱/啥价|{用户名} 看2号链接|稍等亲|#cd:8`
4. 匹配可选 **包含** 或 **全匹配**；未命中且开启 AI 时兜底
5. 不会回复主播自己的发言（含软件发出的自动发言）

---

## 八、多账号

- 基础版：仅「默认账号」
- 专业版：右侧 **账号管理** 点 **添加账号**；每个账号独立连接、独立任务配置
- 删除账号：右侧账号管理卡片上的删除按钮（不能删默认账号；建议先断开连接）

## 九、日常 checklist

- [ ] 卡密未过期（或接受基础版 1 账号）
- [ ] Chrome/Edge 可用，浏览器路径正确
- [ ] 目标平台已开播，中控台 **已连接**（顶栏状态条可见）
- [ ] 发言 / 弹窗 / 回复按需配置并已启动
- [ ] 改配置后如在运行，已停止再开始
- [ ] 勿随意「解除字数限制」（评论过长易风控）

### 专业版过期后

若曾添加过多账号，启动后会提示 **禁用多余账号**：多余账号的连接与任务会断开，但**本地配置与登录态保留**；续充后自动恢复多开。若不需要可手动删除已禁用账号。

## 十、常见问题

**连不上？** 关无头再连；检查浏览器路径；看底部运行日志与弹窗中的具体错误提示。扫码请在约 5 分钟内完成。

**开始任务失败？** 是否已连接中控台？是否当前账号被禁用？日志里是否有报错。

**加不了第二个号？** 基础版限制；去收费计划激活。

**快捷键没反应？** 是否停在「自动弹窗」页；是否与系统快捷键冲突。

**软件显示已发言、直播间没有？** 确认中控台仍已连接；看底部日志是否有发送失败；可尝试关掉无头模式后重连再试。
