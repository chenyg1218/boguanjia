# 播管家 用户教程

顶栏账号切换 + 左侧功能列表 + 主区操作 + 底部运行日志。

**目前仅支持快手小店。** 系统要求：Windows 10 / 11、本机 Chrome 或 Edge。

---

## 一、能做什么

| 功能 | 说明 |
|------|------|
| 打开中控台 | 外置浏览器连接快手小店中控台 |
| 自动发言 | 定时发弹幕；支持变量、随机空格、置顶、一键刷屏 |
| 自动弹窗 | 按商品序号自动讲解弹窗；支持循环次数、快捷键 |
| 自动回复 | 监听评论；关键词批量规则、`{用户名}`、可选脱敏 |
| AI 助手 | 自备 API Key（不进卡密费用） |

**收费不变**：免费版 **1 个账号**；专业版卡密可 **多账号**。功能点不额外收费。

---

## 二、安装与启动

1. 从官方渠道下载安装包（GitHub Releases 或商家提供的链接）
2. 双击安装。若弹出 **「Windows 已保护你的电脑」**（SmartScreen）：
   - 点 **更多信息** → **仍要运行** 即可继续安装
   - 原因是安装包尚未购买代码签名证书，Windows 对「未知发布者」会提示；**不是病毒报毒**
3. 安装完成后打开「播管家」

开发调试：

```bat
cd desktop
pnpm install
pnpm dev
```

---

## 三、收费计划 / 卡密

1. 顶栏点击 **免费版 / 专业版** 徽章，或 **应用设置 → 收费计划**
2. 粘贴卡密 → **激活**（续充叠加时长）
3. 卡密绑机；换机联系商家

未激活也能用：仅默认账号。点右上角 **+** 加号时，免费版会提示开通专业版。

---

## 四、连接中控台（必做）

「打开中控台」页含状态卡片与操作说明。

1. **应用设置 → 浏览器设置**：确认检测到 Chrome/Edge（可自定义路径）
2. 打开左侧 **打开中控台**
3. 平台选 **快手小店**
4. **首次扫码请关闭无头模式**
5. 点 **连接直播控制台**，在弹出浏览器扫码
6. 状态变为绿色 **已连接** 后，再去做发言 / 弹窗 / 回复

掉线后需重新连接。换账号请先断开再连。

---

## 五、自动发言

对应侧栏「自动发言」。

1. 在消息列表添加文案（一行一条）
2. **变量**：`{宝宝/家人/老铁}`，发送时随机选一项  
   例：`欢迎{宝宝/家人}进入直播间`
3. 可勾选 **置顶此消息**（平台支持时）
4. **发送设置**：随机发送、间隔秒数、**插入随机空格**、解除字数限制
5. **一键刷屏**：按列表连发（注意冷却，防误触）
6. 点右上角 **开始任务**

> 任务运行中若改了列表或间隔：请先 **停止** 再 **开始**，页面会有黄色提示条。

---

## 六、自动弹窗

对应侧栏「自动弹窗」（商品列表 / 快捷键配置）。

### 商品列表

- 填写小黄车 **商品序号**（如 `1`、`2`）
- **批量添加**：可用区间/列表一次写入，如 `1-100`、`1,3,5-8`（已有序号会跳过）
- **循环次数**：单品反复弹窗次数（单品循环）
- **单品间隔**：0 表示用全局弹窗间隔
- **弹窗设置**：随机弹窗、全局间隔（秒）

### 快捷键配置

- 组合键映射到一组商品序号（如 `Ctrl+Alt+F1` → `1 2`）
- 一般在「自动弹窗」页激活时使用即可；无需刻意开全局快捷键
- 快捷键请用组合键，避免与系统快捷键冲突

点 **开始任务** 后按间隔自动弹；也可用快捷键手动切商品。

---

## 七、自动回复（快手）

侧栏「自动回复」：左评论列表、右回复预览；可进 **设置**。

1. 先 **开始监听**，再 **开始任务**
2. **关键词回复**：启用后可「批量编辑」  
   格式示例：`音响/音箱|回复A|回复B`（多关键词 `/`，多回复 `|`）
3. 回复内容可用 `{用户名}`；设置里可开 **隐藏用户名** → `@张***`
4. 多条回复会随机选一条；关键词优先于 AI（若同时开 AI）

---

## 八、多账号

- 免费版：仅「默认账号」
- 专业版：右侧 **账号管理** 点 **添加账号**；每个账号独立连接、独立任务配置
- 删除账号：右侧账号管理卡片上的删除按钮（不能删默认账号；建议先断开连接）

---

## 九、日常 checklist

- [ ] 卡密未过期（或接受免费版 1 账号）
- [ ] Chrome/Edge 可用，浏览器路径正确
- [ ] 快手已开播，中控台 **已连接**（顶栏状态条可见）
- [ ] 发言 / 弹窗 / 回复按需配置并已 **开始任务**
- [ ] 改配置后如在运行，已停止再开始
- [ ] 勿随意「解除字数限制」（快手过长易风控）

### 专业版过期后

若曾添加过多账号，启动后会提示 **禁用多余账号**：多余账号的连接与任务会断开，但**本地配置与登录态保留**；续充后自动恢复多开。若不需要可手动删除已禁用账号。

## 十、常见问题

**连不上？** 关无头再连；检查浏览器路径；看底部运行日志与弹窗中的具体错误提示。扫码请在约 5 分钟内完成。

**开始任务失败？** 是否已连接中控台？是否当前账号被禁用？日志里是否有报错。

**加不了第二个号？** 免费版限制；去收费计划激活。

**快捷键没反应？** 是否停在「自动弹窗」页；是否与系统快捷键冲突。
