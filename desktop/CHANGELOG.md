# Changelog



## v1.1.4



### 🚀 新功能



- **会员权益:** 侧栏新增「会员权益」入口，可查看套餐说明并激活卡密

- **配置向导:** 首次使用可按引导快速上手；自动发言 / 弹窗 / 回复等支持分步设置，降低上手门槛

- **使用说明:** 各功能页使用说明改写得更清晰好懂



### 🐞 问题修复



- **小红书 / 蒲公英:** 适配中控台新版商品列表；自动弹窗更稳，讲解时长由弹窗间隔控制，并支持讲解中自动续弹

- **停播检测:** 直播结束后，自动回复、自动发言、自动弹窗会自动停止（覆盖抖音、百应、视频号、快手、淘宝、小红书等）



## v1.1.3



### 🚀 新功能



- **自动回复:** 关键词支持「包含 / 全匹配」；同一规则可配置多条回复并随机发送

- **使用教程:** 侧栏与设置内可一键打开软件使用教程



### 🐞 问题修复



- **自动回复:** 修复 AI / 关键词可能回复主播自己发言的问题

- **自动发言:** 修复界面显示已发送、直播间公屏未出现的问题

- **抖音小店:** 修复连接判定与中控台刷新，避免发言 / 弹窗失效

- **自动弹窗 / 快手:** 更稳地点掉讲解确认弹窗；开播后自动点「我知道了」



## v1.1.2



### 🚀 新功能



- **软件更新:** 支持「更新提示」与「自动更新」开关；开启自动更新时后台下载，退出后安装

- **软件更新:** 默认更新源改为 Gitee（国内）；仍可切换 GitHub / 代理源

- **中控台:** 掉线后可按原因区分处理，支持任务在重连后自动恢复

- **自动弹窗:** 商品列表与批量配置交互优化



## v1.1.0



### 🚀 新功能



- **收费计划:** 基础版 0 元 · 单平台 · 1个账号；专业版 29 元/月 · 单平台 · 3个账号；旗舰版 39 元/月 · 无上限（卡密档位强制执行）

- **多平台:** 新增抖音小店、巨量百应、抖音团购、小红书千帆、小红书蒲公英、视频号、淘宝；保留快手小店

- **中控台:** 支持在界面中切换平台后连接对应中控台



## v1.0.1



### 🐞 问题修复



- **界面:** 修复正式安装包侧边栏图标在 `file` 协议下无法加载的问题



## v1.0.0



### 🚀 新功能



- **播管家** 首个正式版：基于 oba-live-tool 衍生，专注快手小店跟播

- **中控台:** 连接快手小店，支持有头 / 无头模式

- **自动发言 / 自动弹窗 / 自动回复:** 快手小店跟播能力

- **收费计划:** 免费版 1个账号，专业版卡密支持多账号

- **软件更新:** 通过 GitHub Releases 检查与安装更新
